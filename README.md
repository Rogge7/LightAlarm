# 亮屏闹铃（LightAlarm）

一个只在「你正在玩手机」时才响的睡觉提醒闹钟。

- 屏幕**亮着且已解锁** → 全屏提醒页 + 铃声（可选语音播报）
- 屏幕**熄灭或处于锁屏** → 完全静默（不响、不振动、不亮屏、不发通知）
- 支持多条闹钟、按星期重复、系统铃声 / 本地音频 / 自录语音、音量与响铃时长可调、延迟 5/10/15 分钟再提醒
- 响铃方式双通道：**闹铃外放**（走扬声器，像系统闹钟）或 **媒体音**（连蓝牙耳机时只从耳机出）

## 一、功能一览

| 模块 | 说明 |
|---|---|
| 定时提醒 | 任意条数；按星期重复，不勾选则只响一次；默认标签「提醒」 |
| 提醒语 | 每条提醒可单独设置，内置 24 条语库可一键选用 |
| 铃声 | 系统默认闹铃 / 系统铃声列表（点选即试听）/ 本地音频文件 / 自录音 |
| 响铃方式 | 闹铃外放 / 媒体音（默认媒体音，蓝牙耳机不外放） |
| 语音播报 | 响铃时用系统 TTS 朗读提醒语，跟随所选响铃方式走同一通道 |
| 宵禁时段 | 例如 23:00–06:00，时段内只要亮屏就每 15 分钟提醒一次 |
| 连续亮屏 | 连续亮屏超过阈值（默认 45 分钟）提醒休息，事件驱动零耗电 |
| 守护与自检 | 常驻前台服务 + 每 6 小时健康检查，被系统清掉的闹钟自动补排 |
| 记录与状态 | 主界面显示「上一次触发」是响铃还是静默、以及「下一次」时间 |

## 三、云端编译 APK（无需装 Android Studio）

1. 新建 GitHub 空仓库（不要勾 README / .gitignore / license）
2. 把工程根目录下所有文件与文件夹（含 `.github`、`app`、`gradle`）全部上传
3. 进入仓库 **Actions** 标签，会自动开始 `Build LightAlarm APK`
4. 等状态变绿 ✓，点进该次运行，在底部 **Artifacts** 下载 `LightAlarm-apk`
5. 解压得到 **`亮屏闹铃.apk`**，传到手机安装

修改代码后 `git push` 即自动重新编译。

### 发布签名（可选，建议配）

不配置也能编译，但会用 debug 签名，**每次覆盖安装都失败，需要先卸载**。在仓库 Settings → Secrets and variables → Actions 里加 4 个 secret：

| Secret | 值 |
|---|---|
| `KEYSTORE_BASE64` | `[Convert]::ToBase64String([IO.File]::ReadAllBytes("…\lightalarm.jks")) \| clip` |
| `KEYSTORE_PASSWORD` | `lightalarm123` |
| `KEY_ALIAS` | `lightalarm` |
| `KEY_PASSWORD` | `lightalarm123` |

`build.gradle` 会检测 `KEYSTORE_PASSWORD` 是否非空：非空走 release 签名，为空回退 debug 签名。

## 四、安装后必须做的授权（否则可能不响）

打开 App 后，主界面顶部有「运行权限」清单，逐项点开（五项全部就绪时会自动折叠）：

| 权限 | 作用 | 不开的后果 |
|---|---|---|
| 通知权限 | 显示提醒、保证前台服务运行 | 提醒页/通知不显示 |
| 精确闹钟 | 到点准时触发 | 可能延迟几分钟到几十分钟 |
| 忽略电池优化 | 防止系统休眠后限制后台 | 熄屏久了闹钟被延迟 |
| 全屏提醒 | 亮屏时自动弹出提醒页 | 退化为通知横幅（铃声照响） |
| 悬浮窗 | 在刷视频/看小说时也能全屏弹窗 | 可能只弹通知横幅（铃声照响） |
| 允许自启动 | 小米/华为/OPPO/vivo 等必需 | 重启或清后台后闹钟失效 |
| 任务列表锁定 | 防一键清理把进程连带杀掉 | 划掉卡片 = 变相强行停止 |
| 后台常驻守护 | 常驻通知让进程活着，闹钟存活率更高 | 更容易漏响（可选，默认关闭） |

另外几项按需：

- **麦克风**：只在编辑页点「我的录音」时弹窗申请一次
- **闹钟健康检查**：默认每 6 小时自动跑，无需授权；主界面可点「立即自检」

国产手机还需手动操作一步：系统管家 / 手机管家 → 应用管理 → 亮屏闹铃 → 允许「自启动」「后台运行」「锁屏保持运行」「后台弹出界面」，并把电池策略设为「无限制」。

## 五、使用说明

1. 点「＋ 新增闹铃」，选时间。例如设 23:30、00:30、01:30 三个
2. 「重复」勾选星期；**不勾选 = 只响一次**
3. 标签不填默认「提醒」
4. 铃声可选：系统默认闹铃（点选试听）、从系统铃声中选择（点一下即试听）、从本地音频文件中选择、我的录音（可现场录一段，长按列表项可删除）
5. 响铃时长 15/30/60 秒自动停止；音量是 App 内音量（不改系统音量）
6. **响铃方式**：
   - 闹铃外放 —— 走扬声器，像系统闹钟，通常是最大声
   - 媒体音 —— 走媒体通道，插着蓝牙耳机时只从耳机出声，手机上不外放（默认）
7. 提醒语可手写，也可点「从语库选」挑一条内置句子
8. 保存后可用主界面「立即测试」验证：亮屏且解锁时立即响铃；锁屏或灭屏时静默并记录状态
9. 闹铃触发时，全屏页可点「知道了，去睡觉」或「延迟 N 分钟」

### 宵禁时段

主界面「宵禁时段」卡片：开关 + 时段 + 间隔 + 提醒语 + 响铃方式（默认媒体音，默认 23:00–06:00，每 15 分钟）。开启后，时段内只要屏幕亮着且解锁，就按间隔提醒；灭屏或锁屏期间不会累积补响。

### 连续亮屏提醒

主界面「连续亮屏」卡片：开关 + 阈值（30/45/60/90/120 分钟）+ 提醒语，默认 45 分钟。计时靠 `SCREEN_ON` / `SCREEN_OFF` 广播，事件驱动不轮询，灭屏清零，同一段亮屏只提醒一次。该功能依赖后台常驻守护（GuardService）存活。

### 语音播报

主界面底部开关。开启后响铃时用系统自带 TTS 朗读该条提醒语，**AudioAttributes 跟随该条提醒的响铃方式**：选媒体音则 TTS 也走媒体通道（蓝牙耳机出声）；选闹铃外放则走闹铃通道。手机没有中文 TTS 引擎时静默跳过，不影响铃声。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 到点完全不响 | 先看主界面「上次触发」：显示「静默」说明当时屏幕灭或锁屏，属正常设计 |
| 亮屏了但只是通知横幅 | 允许「全屏提醒」；小米/华为还需在应用详情 → 其他权限里允许「后台弹出界面」 |
| 亮屏时完全没有弹窗，只有铃声 | 同上：允许「后台弹出界面」或「显示在其他应用上层」 |
| 闹钟晚了几分钟 | 「精确闹钟」未开启；去系统设置 → 特殊应用权限 → 闹钟和提醒 → 允许 |
| 重启手机后不响 | 打开一次 App，并确保「允许自启动」；主界面会显示下一次时间 |
| 自定义音频不响 | 音频文件被移动/删除，重新在编辑页选一次 |
| 1 小时后才响 | 后台被厂商清理：按上面表格加白名单 |
| 选了媒体音，耳机里没声音、手机外放了 | ① 确认该条闹铃的「响铃方式」是媒体音（老版本创建的闹铃可能还是闹铃外放）；② 蓝牙耳机需处于「媒体音频」已连接状态，只连通话音频不会走耳机 |
| 铃声正常，但语音播报外放了 | 已修复于 v1.4：TTS 现在跟随响铃方式；仍异常时检查系统 TTS 引擎（设置 → 语言与输入 → 文字转语音）是否可用 |
| 强行停止后怎么都不响 | 安卓硬限制：强行停止会清掉所有闹钟与广播，任何 App 都无法自救；请勿在设置里「强行停止」，也不要在任务列表直接划掉（先锁定） |
| 自检说「所有提醒都在」但还是没响 | 说明闹钟还在系统里，问题在权限或后台清理，按权限表格逐项核对 |

## 七、设计说明

- **条件触发**：触发瞬间用 `PowerManager.isInteractive()` + `KeyguardManager.isKeyguardLocked()` 判断，两者同时满足才响铃；否则直接返回，不做任何事（不写通知、不亮屏）。
- **排程**：优先 `AlarmManager.setAlarmClock`（系统时钟 App 同款 API，状态栏显示闹钟图标，存活率最高）；无精确闹钟权限时退化为 `setAndAllowWhileIdle` / `set`。
- **响铃通道**：`Alarm.soundMode` 决定 `AudioAttributes.USAGE_ALARM` 还是 `USAGE_MEDIA`，必须在 `prepare()` **之前** `setAudioAttributes()`，否则会串到媒体声道。TTS 使用同一套 usage。
- **弹窗**：优先悬浮窗（`TYPE_APPLICATION_OVERLAY`）铺满全屏；无悬浮窗权限则尝试直接拉起提醒页；都失败时仍有高优先级全屏通知 + 铃声。
- **宵禁 / 连续亮屏**：不新建数据模型，转成两个伪闹铃（`CURFEW_ID = -1000`、`SCREEN_TIME_ID = -2000`）交给 `AlarmService`，共用同一套弹窗、铃声、TTS、贪睡逻辑。
- **可靠性三层**：① 常驻 `GuardService`（被拉起时自动 `rescheduleAll`）；② 每 6 小时 `HealthReceiver` 用 `PendingIntent.FLAG_NO_CREATE` 检测闹钟是否丢失并补排（`setAndAllowWhileIdle` 省电，正常时静默）；③ `SystemReceiver` 监听开机 / 改时间 / 时区变化 / 应用更新后重排。
- **数据**：全部存本机 SharedPreferences（闹铃 JSON 数组，宵禁与亮屏设置各自独立），无网络、无账号、无权限滥用。录音存 `getExternalFilesDir("recordings")`。
