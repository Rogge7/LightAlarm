# 亮屏闹铃（LightAlarm）

一个只在「你正在玩手机」时才响的睡觉提醒闹钟。

- 屏幕**亮着且已解锁** → 全屏提醒页 + 铃声
- 屏幕**熄灭或处于锁屏** → 完全静默（不响、不振动、不亮屏、不发通知）
- 支持多条闹钟、按星期重复、系统铃声或本地音频、音量/响铃时长可调、延迟 5/10/15 分钟再提醒

## 文件结构

```
LightAlarm/
├── .github/workflows/build.yml     # GitHub 自动编译 APK
├── app/src/main/java/com/balilan/lightalarm/
│   ├── MainActivity.java           # 主界面：闹钟列表 + 权限引导 + 测试
│   ├── EditActivity.java           # 新增/编辑闹钟（时间、星期、铃声、音量…）
│   ├── RingActivity.java           # 全屏提醒页（知道了 / 延迟 10 分钟）
│   ├── AlarmService.java           # 前台服务：播放铃声 + 全屏通知
│   ├── AlarmReceiver.java          # 触发瞬间判断屏幕状态
│   ├── AlarmScheduler.java         # 精确闹钟排程 / 贪睡 / 重启恢复
│   ├── SystemReceiver.java         # 开机、改时间后重排闹钟
│   ├── AlarmStore.java             # 本地存储（SharedPreferences + JSON）
│   └── Alarm.java                  # 闹钟数据模型
└── app/src/main/res/               # 布局、颜色、主题
```

## 一、云端编译 APK（无需装 Android Studio）

1. 新建 GitHub 空仓库（不要勾 README / .gitignore / license）
2. 把工程根目录下所有文件与文件夹（含 `.github`、`app`、`gradle`）全部上传
3. 进入仓库 **Actions** 标签，会自动开始 `Build LightAlarm APK`
4. 等状态变绿 ✓，点进该次运行，在底部 **Artifacts** 下载 `LightAlarm-debug-apk`
5. 解压得到 `app-debug.apk`，传到手机安装

修改代码后重新上传（或 `git push`）即自动重新编译。

## 二、安装后必须做的授权（否则可能不响）

打开 App 后，主界面顶部有「运行权限」清单，逐项点开：

| 权限 | 作用 | 不开的后果 |
|---|---|---|
| 通知权限 | 显示提醒、保证前台服务运行 | 提醒页/通知不显示 |
| 精确闹钟 | 到点准时触发 | 可能延迟几分钟到几十分钟 |
| 忽略电池优化 | 防止系统休眠后限制后台 | 熄屏久了闹钟被延迟 |
| 全屏提醒 | 亮屏时自动弹出提醒页 | 退化为通知横幅（铃声照响） |
| 悬浮窗 | 在刷视频/看小说时也能全屏弹窗 | 可能只弹通知横幅（铃声照响） |
| 允许自启动 | 小米/华为/OPPO/vivo 等必需 | 重启或清后台后闹钟失效 |

国产手机还需手动操作一步：系统管家 / 手机管家 → 应用管理 → 亮屏闹铃 → 允许「自启动」「后台运行」「锁屏保持运行」「后台弹出界面」，并把电池策略设为「无限制」。

## 三、使用说明

1. 点「＋ 新增闹铃」，选时间。例如设 23:30、00:30、01:30 三个
2. 「重复」勾选星期；**不勾选 = 只响一次**
3. 铃声可选「系统默认闹铃」、「从系统铃声中选择」、「从本地音频文件中选择」
4. 响铃时长 15/30/60 秒自动停止；音量是 App 内音量（不改系统音量，但受系统闹铃总音量影响）
5. 保存后可用「立即测试」验证：亮屏且解锁时立即响铃；锁屏或灭屏时静默并记录状态
6. 闹钟触发时，全屏页可点「知道了，去睡觉」或「延迟 N 分钟」（贪睡时长在编辑页设置）

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 到点完全不响 | 先看主界面「上次触发」：显示「静默」说明当时屏幕灭或锁屏，属正常设计 |
| 亮屏了但只是通知横幅 | 去「全屏提醒」权限里允许本应用使用全屏通知；小米/华为还需在应用详情 → 其他权限里允许「后台弹出界面」或「显示在其他应用上层」 |
| 亮屏时完全没有弹窗，只有铃声 | 同上：允许「后台弹出界面」；系统限制下无法保证 100% 自动弹页，铃声与通知不受影响 |
| 闹钟晚了几分钟 | 「精确闹钟」未开启；去系统设置 → 特殊应用权限 → 闹钟和提醒 → 允许 |
| 重启手机后不响 | 打开一次 App，并确保「允许自启动」；主界面会显示下一次时间 |
| 自定义音频不响 | 音频文件被移动/删除，重新在编辑页选一次 |
| 1 小时后才响 | 后台被厂商清理：按上面表格加白名单 |

## 五、设计说明

- 触发瞬间用 `PowerManager.isInteractive()` + `KeyguardManager.isKeyguardLocked()` 判断，两者同时满足才响铃；否则直接返回，不做任何事。
- 响铃由前台服务（`mediaPlayback` 类型）播放 `STREAM_ALARM`，Android 12+ 的精确闹钟广播属于后台启动前台服务的豁免场景。
- 全屏提醒依赖全屏 Intent 通知；亮屏解锁时系统通常不会自动拉起页面，因此优先使用悬浮窗（`TYPE_APPLICATION_OVERLAY`）铺满全屏弹窗，没有悬浮窗权限时再尝试直接拉起提醒页，都失败时仍有高优先级横幅 + 铃声。
- 所有数据仅存本机 SharedPreferences，无网络、无账号、无权限滥用。
